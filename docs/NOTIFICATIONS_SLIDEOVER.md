# راهنمای جامع مرکز اعلان‌ها و هشدارهای پنل ادمین (Notifications Slideover)

این سند جزئیات فنی، معماری، انطباق با دیزاین سیستم و نحوه اجرا و آزمایش مرکز اعلان‌ها و هشدارهای بلادرنگ (`NotificationsSlideover`) در پنل مدیریت VAPELAB را تشریح می‌کند.

---

## ۱. هدف و فلسفه طراحی

مرکز اعلان‌های پنل مدیریت VAPELAB با الهام از ساختار رسمی **Nuxt Dashboard Template** طراحی و پیاده‌سازی شده است تا هشدارهای حیاتی سیستم (نظیر سفارش‌های جدید، درخواست‌های تسویه حساب تأمین‌کنندگان، کسری موجودی انبار و رویدادهای امنیتی) را به شکلی مدرن، غیرمزاحم و با دسترسی سریع به مدیران و تأمین‌کنندگان نمایش دهد.

---

## ۲. ریشه‌یابی باگ‌های قبلی و رفع ریشه‌ای (Root Cause Analysis & Fixes)

در نسخه‌های اولیه، نمایش اعلان‌ها با باگ‌های بصری متعددی در مرورگر کاربر مواجه شده بود:

| مشکل مشاهده‌شده | علت فنی ریشه‌ای | راهکار قطعی اعمال‌شده |
| :--- | :--- | :--- |
| **فشرده‌شدن و برش کادر اعلان در بالای صفحه** | رندر شدن کامپوننت درون `<header>` با ارتفاع محدود ۶۴ پیکسل و ایجاد Stacking Context مجزا توسط کلاس `backdrop-blur-xl`. | استفاده از ترکیب `<ClientOnly>` و `<Teleport to="body">` جهت رندر مستقیم در بالاترین لایه DOM و خارج از محدوده عناصر بلورشده هدر. |
| **عدم تاریک‌شدن پس‌زمینه (Backdrop)** | پوزیشنینگ ناقص لایه ماسک مشکی پشت اسلاید‌اور. | تعریف لایه `fixed inset-0 bg-black/75 backdrop-blur-sm z-[99998]` با ترنزیشن فید نرم. |
| **پرش انیمیشن در چیدمان راست‌چین (RTL)** | وابستگی به کلاس‌های غیراستاندارد بدون تعریف ترنزیشن Vue. | پیاده‌سازی ترنزیشن نرم بومی Vue 3 با ترنزیشن `transform` از `-translate-x-full` تا `translate-x-0` از سمت چپ صفحه (بدون تداخل با سایدبار راست‌چین). |
| **ناهماهنگی رنگ‌ها با هویت بصری** | استفاده از رنگ سبز دیفالت فریم‌ورک (`#00DC82`). | مهاجرت کامل به پالت رسمی بنفش لوکس و آبی الکتریک VAPELAB (`#8B5CF6` و `#3B82F6`). |

## ۴. اجزا و ویژگی‌های رابط کاربری (UI Features)

1. **دکمه زنگوله در هدر (`UDashboardNavbar.vue`)**:
   - دارای نشانگر عددی تپنده برای اعلان‌های خوانده‌نشده (`unreadCount`).
   - کلید میانبر صفحه‌کلید (`N`) جهت باز و بسته کردن سریع بدون ماوس.
2. **هدر اسلاید‌اور**:
   - عنوان فارسی «مرکز اعلان‌ها و رویدادها» به همراه نشانگر تعداد اعلان جدید.
   - دکمه سریع «خواندن همه» برای صفر کردن نوتیفیکیشن‌ها با یک کلیک.
   - دکمه بستن با کلید میانبر `ESC`.
3. **کنترل سگمنتد فیلتر (Segmented Tabs)**:
   - تب «همه» همراه با شمارنده کل اعلان‌ها.
   - تب «خوانده‌نشده» همراه با بج برجسته برای فیلتر سریع پیام‌های نیازمند اقدام.
4. **کارت‌های نوتیفیکیشن دسته‌بندی‌شده**:
   - **سفارشات (`order`)**: آیکون خرید و بج بنفش (`#8B5CF6`)
   - **امور مالی و تسویه (`settlement`)**: آیکون کیف‌پول و بج آبی الکتریک (`#3B82F6`)
   - **کسری موجودی انبار (`inventory`)**: آیکون هشدار و بج رز/قرمز (`#F43F5E`)
   - **امنیت و احراز هویت (`system`)**: آیکون سپر و بج فیروزه‌ای (`#06B6D4`)
   - نشانگر تپنده بنفش برای پیام‌های جدید.
   - لینک هدایت مستقیم («مشاهده جزئیات») به صفحات مربوطه (مانند `/admin-panel/orders` یا `/admin-panel/finance/settlements`).
5. **وضعیت بدون اعلان (Empty State)**:
   - نمایش پیام و تصویر گرافیکی زیبا هنگام خالی بودن لیست خوانده‌نشده‌ها یا کل صندوق.
6. **فوتر اسلاید‌اور**:
   - نمایش وضعیت آنلاین بودن ارتباط بلادرنگ سیستم با پالس سبز رنگ.
   - دسترسی مستقیم به صفحه تنظیمات اعلان‌ها (`/admin-panel/settings#notifications`).

## ۵. معماری فایل‌ها و مدیریت وضعیت (Architecture & State)

```text
app/
├── components/
│   └── dashboard/
│       ├── NotificationsSlideover.vue   # کامپوننت اصلی کشوی اعلان‌ها با تله‌پورت به بادی
│       └── UDashboardNavbar.vue         # دکمه فراخوان زنگوله و نمایش بج در نوبار
├── composables/
│   └── useDashboard.ts                  # استیت مرکزی اعلان‌ها و اکشن‌های خواندن/بستن
└── layouts/
    ├── admin.vue                        # اتصال سراسری کشو به لایه ادمین
    └── supplier.vue                     # اتصال سراسری کشو به لایه تأمین‌کننده
```

### متدهای موجود در `useDashboard`:
```typescript
const {
  isNotificationsSlideoverOpen, // مقدار بولین وضعیت باز/بسته بودن
  notifications,                // لیست واکنش‌گرای اعلان‌ها
  unreadCount,                  // تعداد خوانده‌نشده‌ها (محاسبه‌شده)
  toggleNotifications,          // سوییچ وضعیت کشو
  openNotifications,            // باز کردن کشو
  closeNotifications,           // بستن کشو
  markAllRead,                  // علامت‌گذاری همه به عنوان خوانده‌شده
  markAsRead,                   // علامت‌گذاری یک مورد بر اساس شناسه
} = useDashboard();
```

## ۶. دستورالعمل اجرا و نحوه تست (Execution & Testing Guide)

### ۱. اجرای محیط محلی

برای اجرای پروژه در محیط Development، دستورات زیر را در دو ترمینال مجزا اجرا کنید:

```bash
# ترمینال ۱: اجرای بک‌اند NestJS
cd backend
npm run start:dev

# ترمینال ۲: اجرای فرانت‌اند Nuxt 3
npm run dev
```

> **نکته**: در صورتی که تمایل دارید کل پروژه را با داکر اجرا کنید:
> ```bash
> docker compose up -d --build
> ```

### ۲. مراحل تست در مرورگر

1. مرورگر را باز کرده و به مسیر پنل ادمین مراجعه کنید:
   [http://localhost:3001/admin-panel](http://localhost:3001/admin-panel)
2. در صورتی که نیاز به لاگین داشتید، از حساب ادمین استفاده کنید.
3. در نوار بالای صفحه (Header)، روی آیکون زنگوله کلیک کنید یا کلید `N` را روی کیبورد فشار دهید.
4. **بررسی ظاهر**:
   - کشوی اعلان‌ها باید به‌صورت تمام‌قد (`Full Height`) و با انیمیشن روان از سمت چپ صفحه باز شود.
   - پس‌زمینه صفحه اصلی تیره و تار (Backdrop Blur) گردد.
   - استایل‌ها و رنگ‌بندی باید دقیقاً بر پایه پالت بنفش و تیره VAPELAB باشد.
5. **بررسی کارکردها**:
   - سوییچ بین تب «همه» و «خوانده‌نشده».
   - کلیک روی یک اعلان و بررسی ثبت وضعیت خوانده‌شدن آن.
   - کلیک روی دکمه «خواندن همه» و بررسی صفر شدن نشانگر زنگوله.
   - کلیک روی لینک «مشاهده جزئیات» و بررسی هدایت به صفحه هدف.
   - فشردن کلید `Escape` یا کلیک روی پس‌زمینه تیره برای بستن کشو.

### ۳. اعتبارسنجی TypeCheck و سلامت کد

```bash
# اعتبارسنجی فرانت‌اند با vue-tsc
npm run typecheck

# بیلد بک‌اند NestJS
npm run --prefix backend build
```
هر دو فرمان فوق باید بدون هیچ خطایی (`0 errors`) به پایان برسند.
